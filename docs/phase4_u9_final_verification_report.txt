5. SYNC PROTOCOL AUDIT (P4-U5)
-----------------------------------------------------------------------
  Authentication: cashier JWT (guard chain) + device credential
    header, verified against the operation's OWN device, constant-time;
    device must be ACTIVE (suspension revokes sync). VERIFIED.
  Authorization: current cashier identity + current pos:create;
    demotion -> 403 with the operation left PENDING (D7). VERIFIED.
  Idempotency: duplicate op (concurrent or sequential) returns the
    same durable result; rejected replay returns the same rejection.
    VERIFIED.
  Concurrency: the DB-arbitrated processedAt claim guarantees
    exactly-once execution — one Order, one Payment, one inventory
    decrement; both concurrent callers receive the same result.
    VERIFIED (U5/U6/U7/U8 race suites).
  Business authority: server price (D3), server stock (D4), server
    payment amount (T5-derived from the Order), server context. The
    device-observed price is ONLY the PRICE_CHANGED comparator.
    VERIFIED.
  Session: closed historical sessions execute after full revalidation
    (allowClosedSession, internal-only); no silent rebinding. VERIFIED.
  Transactions: T1/T5/T2 are independently atomic; validation runs
    before any mutation; stale-claim (crash) recovery is documented
    and deterministic. VERIFIED.
